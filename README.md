# WordsHelper 使用说明

## 项目简介
**WordsHelper** 是一个用于帮助用户学习生词的小工具。通过输入单词列表，程序可以生成单词的扩展信息（如短语、释义、读音等）以及相关的故事和总结，并将结果保存为 Markdown 文件，方便用户查阅。

---

## 功能特点
1. **单词扩展**：
   - 自动生成单词的短语、短语释义、读音和中文释义。
2. **故事生成**：
   - 根据单词生成相关的故事和总结。
3. **多线程处理**：
   - 使用多线程技术并发处理单词扩展和故事生成，提高效率。
4. **结果保存**：
   - 支持将结果保存为 Markdown 文件，文件名按日期命名。
5. **灵活配置**：
   - 支持通过 `config.yml` 文件自定义模型参数、API 地址和输出路径。

---

## 使用步骤
1. **准备工作**：
   - 确保已安装 Python 3.8 或更高版本。
   - 安装必要的依赖库（如 `tqdm`、`PyYAML` 等）。

2. **运行程序**：
   - 下载或克隆项目到本地。
   - 确保 `config.yml` 文件与程序主文件位于同一目录。
   - 运行以下命令启动程序：
     ```bash
     python src/main.py
     ```

3. **操作流程**：
   - 按照提示选择包含单词的文本文件。
   - 程序会自动处理单词并生成结果。
   - 如果配置了 `output_dir`，结果文件会自动保存到指定目录；否则，用户需手动选择保存路径。

## 配置文件说明
程序通过 `config.yml` 文件进行配置，以下是配置文件的详细说明：

### 配置文件示例
```yaml
# 模型相关配置
model: "gpt-4"                # 使用的语言模型名称，例如 "gpt-4" 或 "gpt-3.5"
max_tokens: 200               # 模型生成内容的最大长度（单位：token）
temperature: 0.8              # 模型生成内容的随机性，值越高生成内容越多样化（范围：0.0 ~ 1.0）

# API 配置
api_url: "https://api.example.com"  # 模型 API 的请求地址
api_key: "your-api-key"             # 模型 API 的访问密钥
# api_key: "" # API 密钥（可以手动填写或从环境变量中加载）
# 如果没有配置密钥，则会读取 SILICON_API_KEY 环境变量

# 输出文件配置
output_dir: "d:/FileDownload/Output"  # 生成结果文件的保存目录
```

### 配置项说明
1. **模型相关配置**：
   - `model`：指定使用的语言模型名称。
   - `max_tokens`：生成内容的最大长度。
   - `temperature`：控制生成内容的随机性。

2. **API 配置**：
   - `api_url`：模型 API 的请求地址。
   - `api_key`：模型 API 的访问密钥。（可以手动填写或从环境变量中加载）

3. **输出文件配置**：
   - `output_dir`：指定生成结果文件的保存目录。如果未配置，程序会弹出保存对话框。

## 注意事项
1. **配置文件**：
   - 请确保 `config.yml` 文件与程序主文件位于同一目录。
   - 如果未正确配置 `api_key`，程序可能无法正常运行。

2. **输入文件格式**：
   - 输入文件应为 `.txt` 格式，每行包含一个或多个单词，单词之间用空格分隔。

3. **输出文件**：
   - 如果配置了 `output_dir`，结果文件会自动保存到指定目录，文件名格式为 `{YYYY-MM-DD}.md`。
   - 如果未配置 `output_dir`，程序会弹出保存对话框，用户需手动选择保存路径。

4. **依赖库**：
   - 请确保已安装以下依赖库：
     ```bash
     pip install tqdm pyyaml
     ```

5. **运行环境**：
   - 程序支持 Windows 和 macOS，建议使用 Python 3.8 或更高版本。

---

## 常见问题
1. **程序无法运行**：
   - 检查是否正确安装了 Python 和依赖库。
   - 确保 `config.yml` 文件存在且格式正确。

2. **结果文件未生成**：
   - 检查 `output_dir` 是否具有写入权限。
   - 如果未配置 `output_dir`，确保在弹出的保存对话框中选择了保存路径。

3. **API 请求失败**：
   - 检查 `api_url` 和 `api_key` 是否正确配置。
   - 确保网络连接正常。
